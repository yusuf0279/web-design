# Web Design skill

Codex skill for researching, planning, building, and visually reviewing distinctive multi-page websites as Next.js applications.

The installable skill is at the repository root (`SKILL.md`). Supporting workflow references, palette guidance, anti-slop checks, agent metadata, and the visual gate script are included.

## Install

Copy this repository's contents into a Codex skills directory named `web-design`, for example:

```sh
mkdir -p ~/.codex/skills/web-design
cp -R . ~/.codex/skills/web-design/
```

Restart Codex or start a new session to load changes to an already-running skill.
